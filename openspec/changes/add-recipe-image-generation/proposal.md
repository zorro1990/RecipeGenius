## Why
目前的菜谱生成结果缺少直观的菜品图片，用户需要依靠文字想象，体验较弱。接入火山引擎 Seedream 4.0 文生图能力，可以根据菜谱内容自动生成配图，让“菜谱概览”更具吸引力，也方便用户快速理解成品外观。

## What Changes
- 在右上角的 API 配置入口中，新增 Seedream 图片生成 API 的 Key 输入与保存，支持本地加密存储与校验提示。
- 菜谱生成流程中，为每道菜谱构造符合文生图提示词指南的中文/英文结合 prompt，并调用 Seedream 4.0 API 生成图片。
- 在“菜谱概览”模块中展示生成的菜品图片，处理加载/失败状态，并允许用户重新触发图片生成。

## Impact
- Affected specs: recipe-imagery
- Affected code: API 配置面板、菜谱生成 orchestrator、`RecipeOverview` 组件及相关数据流

## Acceptance Criteria
- 未配置 Seedream Key 时，尝试生成菜谱配图会阻止调用并提示用户完善 API Key。
- 用户保存有效 Seedream Key 后，刷新页面仍能直接触发图片生成并看到“保存成功”的反馈。
- 对任一菜谱可生成符合指南结构的中英 prompt，并在日志或调试输出中可验证关键字段被包含。
- “菜谱概览”在加载配图时出现骨架或进度反馈，成功后展示图片与替代文本，失败时给出重试按钮且文字内容不受影响。
- Seedream 生成结果被缓存；同一菜谱再次打开时不会重复调用 API，除非用户手动重试。
